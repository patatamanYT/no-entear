# Actividad 1 – Visualización de datos (US Police Shootings, 2015)

## Archivos a entregar

```
Actividad1_Visualizacion/
├── Actividad_1_Visualizacion_Datos.ipynb
└── datos/
    ├── PoliceKillingsUS4.csv
    ├── MedianHouseholdIncome2015.csv
    ├── ShareRaceByCity2.csv
    ├── population2015.csv
    └── Races.csv
```

(`PercentagePeopleBelowPovertyLevel.csv` y `PercentOver25CompletedHighSchool.csv` también están en `datos/`, pero el notebook no los usa.)

## Cómo ejecutarlo

1. Mantener la carpeta `datos/` junto al notebook.
2. Requisitos: Python 3, `pandas`, `numpy`, `matplotlib` y Jupyter.
3. Abrir el notebook y usar **Run All** (Kernel → Restart & Run All).
